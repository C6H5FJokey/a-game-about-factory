# 视觉与模拟接口交接

场景与操作见[游戏规格的视觉与交互](game-spec.md#视觉与交互)。抽屉开合、移图、悬浮提示和槽位选择是前端状态。库存、建设和章节推进由 Rust 模拟结算。

## 当前接入

| 界面动作 | 模拟依据与结算 |
|---|---|
| 查看持有、进料与出料 | 持有量来自 `Meta.Stock`。设备快照发布槽位角色、物品 ID、当前量、容量及手动操作权限。空槽可检查。发货站的物资共用装箱容量，到货站的出料由本地线路接走，外城地面站通过物流补给。 |
| 拖拽送料或取出 | 从持有栏拖入允许手动投料的进料槽，可手取的进料、出料和在途槽可拖回持有栏。滚轮、长按横滑及数量输入框用于调量，点选和键盘也能操作。直到放入有效目标才提交命令，由模拟校验实时库存、容量和端点身份。第一次给压制台送料只结算一份并推进教学。 |
| 手采与机器进度 | 前端负责按钮按住 450 毫秒的周期及取消。每次填满发送一次现有 `Gather`，由模拟结算实际入库。机器细条使用 `Field.Progress` 和目录配方的周期长度。 |
| 预览建筑 | 模拟目录发布设备材料、解锁阶段与额定功率，快照发布实时解锁标记。简易采矿机从开场即可用常规建造流程安放。模拟确认时扣除铁矿，旧档已打包的机器优先用于安放。 |
| 查看设备功率 | 快照记录各设备当步的需求、用电、发电、充电和放电，单位为十分之一兆瓦。目录发布额定值，蓄电池同时由 `Field.Energy` 显示储能。 |
| 拒绝或竞态 | 相同格重建设备会获得新身份。旧的转移请求会被拒绝。模拟还会拒绝错误物品、满槽、空来源或仅支持自动运输的端点。界面显示真实结算量，并用新快照更新数量。 |

回归覆盖首台采矿机出料、压制台首次手送、部分取料与送料、满槽、类型错误、设备重建、班线装箱、外城操作权限和自动输送。手送与输送带接收共用容量计算。

## 取料端点

- 模拟分别发布手动放入和手动取出权限。允许手取的槽位通过格号、设备身份、角色、物品 ID 和数量提交 `Transfer`。工序开始时占用配方材料，玩家可取回进料槽内余料。发货站手动装箱，到货站和外城地面站由物流网络交接。
- 带上货物通过 `TakeCargo` 提交对应格、通道、物品和双重身份。货物离格或设备重建时模拟拒绝。队列摘除与持有量增加同时结算。见[输送带与物流装置交接](conveyor-handoff.md#带上取货与动效)。
- 槽位选择、拖拽和调量保留前端选择。模拟提交才变动物资。请求量超过当前余量时返回实际取出数量。回归核对工序占料后只取走余料、错误角色或物品时库存一致，以及收货后旧请求失效。

## 物资目录与周期

- 模拟从生成的物品表读取独立堆叠上限，省略时为 100。顶栏显示总占用，物品简报显示该物品的描述与单格上限。两种堆叠上限可同时占格，部分栈可补齐。
- 模拟发布所选配方和受模块影响的有效加工周期。设备进度条以该周期为分母，矿机进度读取目录中的矿机周期。

## 手工制作

- 配方可声明 `handcraft`，其中 `ticks` 为 30 Hz 模拟步，`unlockStage` 为开放阶段，可用 `inputs` 指定手工配比。界面按目录显示已开放配方、材料、产物和周期，缺料显示红字。
- 开始、取消和完成均由模拟核对制作会话。完成时再校验用料和容量，一次扣料并入包。提前松手取消时保留材料。旧战役使用原来的手制结构件入口。

## 配方选择

- 新加工设备以未选配方状态建成。选择后开放有效端口，每台设备按兼容配方和解锁状态校验。设备面板展示用料、产物、周期和功率。[产物与配方换版](recipe-handoff.md)
- 换方要求当前工序已完成且进出槽为空。输送带上的货物保留，按新端点判定是否可送入。换方使旧槽位请求失效，装配台具备未选配方、缺料、缺电和正常加工状态。
- V10 持久化设备与蓝图的稳定配方 ID。旧战役以原目录恢复固定工序、库存和在途货物。

## 蓝图库

- 本局蓝图库随存档保存。标准厂段以预设展示。每份自定义蓝图有稳定 ID、名称和布局版本。列表提供尺寸、设备数、材料需求和用于预览的布局。
- 框选保存提交两角格与名称。模拟从当下地图读取可复制设备和电缆，每份布局的框选范围上限为 250 格。新增、重命名和删除均按条目结算。
- 预览展开该 ID 与版本的布局。确认时提交锚点、ID、布局版本和旋转步数。模拟复核地形、占用、解锁与套件数量。失败时地图和材料均保持提交前的状态。
- V5 起存档包含蓝图库，V11 支持 V4 至 V10 战役导入。旧浏览器单份蓝图通过布局校验后，作为「旧版厂段」迁入一次。已有迁移标记时再次加载不会重复新增。评审存档与玩家存档分开，重载评审场景重新使用样本存档。

回归覆盖先后保存 A、B、分别部署、重命名 A、删除 B、导出后恢复两条记录，以及不存在的条目、布局版本不符、占用和越界。失败后的存档比较确认材料和地图均未变化。

## 矿机等级

- 目录显示已开放的简易、工业和强化工业等级，发布等级 ID、允许的矿种、解锁条件和建造材料。各级矿机按落点开采当地矿物。简易矿机对各矿种使用同一周期，工业和强化工业矿机使用对应矿种的配方。预览显示产物和速度，用电设备另显示功率。现场产物槽和图标对应该矿脉。
- 施工提交矿机等级、格号与朝向。模拟根据矿脉及解锁状态解析产物和配方。实际快照同时返回等级和工作矿种，原有生产、出料和章节计数继续使用真实产物。
- V5 存档和新蓝图以工业等级保存钻机。恢复 V4 时按原坐标保留矿种、方向、工序和库存。旧蓝图中的矿种钻机迁为工业等级，部署到其他已开放矿脉时采用新落点的配方。

回归覆盖简易矿机在四种矿脉上的产出、手动取矿及存档恢复，以及空地、占用、尚未开放矿脉的拒绝。

- 新战役的各级矿机均支持开采铁矿、铜矿、硅矿和煤矿。简易矿机使用手动取料。导入的旧战役可继续运行原先的简易矿机自动出料线路。[开场衔接](first-miner.md#衔接加工与自动送料)
