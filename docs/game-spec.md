# 《把白昼送回去》游戏规格

## 游戏目标与范围

玩家在一颗自转锁定行星的永夜侧经营工厂，用铁矿、硅矿和煤建造并发射轨道反射镜。镜阵按已知的轨道时刻表轮流照亮三座城市。玩家要让维持镜阵运行的地面工厂持续供料和供电，完成三城照明验收。

本作采用单人固定地图，通关后可继续扩建。桌面键鼠和移动触屏均须能完成主线，包含建造、排障、镜阵运行、存档和读档。

新游戏从曙港最近的铁矿开始。玩家空手采矿，用亲手收集的材料制作第一台简易采矿机。起步区只包含铁矿，玩家取出第一份机采矿后即可探索整张地图。矿脉固定分布，铜矿、煤矿和硅矿离起点依次更远，玩家可以自由选择采集顺序。[地图边界与矿物分布](first-miner.md#地图边界与矿物分布)

### 胜利条件

1. 发射所需镜阵模块，接通各城地面站的供料和供电。
2. 按轨道顺序连续完成三轮三城照明。每个窗口内，地面站需持续满足校准芯消耗和跟踪功率。
3. 第三轮结束时，每个地面站的校准芯储备和指定供电区的可用储能达到该站公开的下一轮准备线。准备线按关卡参数计算并在启动验收前显示。

已发射的镜阵在失败后保留。失败记录首个断供的时间、位置和原因，并允许玩家单独复演失败窗口。单站复演独立于三城验收的连续轮次。验收完成时，地图依次呈现光带扫过工厂和三座城市亮起的过程。

## 原料、能源与物流

### 原料与工艺

材料层级、单批配比、周期与基准产线见[产物与配方换版交接](recipe-handoff.md)。下表概括新游戏的用途。

| 物料 | 来源与用途 |
|---|---|
| 铁矿 | 前期手采和建造简易采矿机。炼成铁锭后供应结构件、铆钉和电枢。 |
| 铜矿 | 开场手采，制成铜锭和铜线供接线。铜线也用于电池、电枢和校准芯。 |
| 硅矿 | 炼成硅锭并加工光学基片，或和铁锭批烧成硅铁坯。光学基片供应镜片与校准芯。 |
| 煤 | 从煤矿开采，同时供应火电站与发射台。发射批次增加时，玩家需要在两者之间协调输送。 |
| 镜阵模块 | 由铆接框架、镜片和硅铁坯拼接，经发射台送入轨道，扩大可用镜阵。 |
| 标准设备套件 | 由工厂生产，供建造站安装成套厂段。厂段本身能继续生产后续扩建所需套件。 |

### 加工设备与配方

加工设备建成后先进入「未选配方」。玩家在设备详情中选择一条已开放且兼容的配方，随后该设备才可进料和加工。配方由数据定义，决定进出料种类、数量和基础周期。同一设备可提供多条兼容配方，同一产物也可有多条生产路线。

| 设备 | 适用配方 |
|---|---|
| 冶炼炉 | 一种原矿冶炼成锭 |
| 批烧炉 | 含原矿的多材料配方 |
| 装配台 | 一种已加工材料 |
| 组装机 | 两种已加工材料 |
| 拼接站 | 三种已加工材料 |

输入数按不同物品种类计。例如两份光学基片仍属于一种输入。

装配台需要接入电网。选定配方、备齐原料且供电充足时，装配台才推进加工。

### 手工制作

「操作 → 手工制作」按配方逐行展示玩家已解锁且允许手工制作的产物，每行显示物品图标和「产物 × 数量」。点一行展开所需材料和「长按制作」按钮。材料不足时配方行文字标红，展开后只标红缺少的材料，按钮保留并禁用。补齐材料后按钮自动恢复可用。

按住制作按钮时，底部细条从左向右填充。填满结算一批，继续按住且材料仍够时可制作下一批。松手或离开制作界面会取消未完成的进度。原料消耗和产物入包由模拟一次结算。

每条配方分别定义设备基础周期与可选的手工制作周期。手工周期可短于、等于或长于设备周期，手工解锁条件可独立于设备配方。显式开放手工制作的配方进入该列表。新游戏开场手制铁锭、铜锭和铜线，用于造炉、发电与接线。[手工制作交接](inventory-handoff.md#手工制作) · [产物表](recipe-handoff.md#产物表)

### 电网与日出窗口

- 电网按接线划分供电区。每区结算发电、负荷、负载优先级和电池的充放电。电池的可用容量、最大充电功率和最大放电功率分别参与结算。
- 简易采矿机自带独立动力，产出的矿保存在自身出料槽内，通过手动取料转入背包。自动出矿和接带教学由有自动出料能力的设备承担。
- 发射和镜阵跟踪产生限时高负荷。地面站预告窗口起止、进料速率和所需功率。玩家可以用备料、储能、基荷、负载优先级或错峰生产满足同一验收条件。
- 成功运行第一城的照明窗口后，光带扫过矿站的太阳能阵列。后续供电取决于镜阵路径、实际照明时段和已接入的接收设备。太阳能的窗口外缺口由基荷或储能承担。
- 稳定供电、定时运行、缺料、缺电和出货堵塞须能通过设备检查与诊断面板区分。玩家从告警可定位地图对象，并沿相关物流或电网追查。

### 本地运输与跨区供给

- 本地输送带有方向、在途货物位置和运输时间。物料按队列推进，末端堵塞会回传。缓冲仓可暂存物料，入出料端口受吞吐限制。
- **普通带直接合流**。同一格可从后方与两侧接入，沿输送带箭头从唯一出口出货。每次出口有可用位置时，优先接入已经到达的后方来料，侧线使用剩余的输送机会。两侧同时可送入时按模拟的确定顺序结算。
- **合流器**。同样从后方与两侧进货、沿唯一出口出货。合流器在就绪入口间轮流取货，空路跳过，恢复来料后参与轮转。一路有货时可用满该装置当前可用的吞吐。直接合流和合流器都受合流格、下游带速和回压限制。[合流与交叉交接](conveyor-handoff.md#合流与交叉)
- 每座储物仓拥有独立库存，容量以储物格数表示。玩家打开该仓即可存取，输送带也从该仓收发物资。[储物仓交接](inventory-handoff.md#储物仓)
- 配方换版以每分钟 60 份铁矿冶炼成 60 份铁锭为一条基准铁线。四级输送带在 1× 模拟速度下，每通道额定吞吐依次为 60、120、270、600 件/分钟，一级带可接满一条基准铁线。[四级带速](conveyor-handoff.md#配方换版后的四级带速)
- 跨区班线按固定线路和班次运输货箱。站场负责装卸和解箱，末端继续由本地皮带供料。路线容量、班次、装卸和站场库存共同决定交付量。
- 第二城附近有硅矿，铁和煤依赖跨区供应。集中生产后运输成品、就地加工后补齐短缺原料，两种方案均应有可通关布局。
- 蓝图保存布局与配方配置。玩家指定位置并接通外部物料、电网接口，建造站按物料清单分配实际库存并安装。多个齐套的厂段可并行部署。资源分配与建造由同一模拟权威确认。

## 游戏进程

### 机制如何进入玩家视野

每个新机制都要回答一个玩家已经遇到的问题。界面同一时刻只突出一个可以动手的目标。新词第一次出现时，玩家当场就能使用它，或已经知道如何取得它所需的材料。一次操作后的变化应能在地图上的原位置看见，例如矿石进入机器的出料格、皮带把原料送进加工口、充电后的地面站撑过用电高峰。

章节解锁以模拟中已经发生的行为为准。阅读说明、打开页面和经过一段时间都不能代替实际产出或交付。初次成功后，给玩家一个能独立运用同一机制的机会，例如把第二条短带接到另一处入口。后续任务可以自然承担这次检验，玩家自行完成的有效布局同样算数。

| 玩家遇到的问题 | 此时引入的能力 | 玩家看得见的通过证据 |
|---|---|---|
| 每份铁矿都要亲手去采 | 长按矿点手采，再从常规建造目录用铁矿安放简易采矿机 | 玩家停止采集后，自己安放的机器在原矿点采出第一份铁矿。 |
| 矿已经有了，第一批设备需要用锭和铜线建造 | 手工制作铁锭、铜锭和铜线，建炉和发电机，铺铜线电缆。给冶炼炉选铁锭配方，再给装配台选结构件配方。 | 首个电网运转，玩家用冶炼取得的铁锭制成第一批结构件。 |
| 手动送料已经学会，玩家还在搬运物料 | 先让玩家亲手取料、送料并看到产出，再用已有自动出料能力的设备与一台已选配方的加工设备教学短皮带。第一处连接只涉及一个来源和一个目的地。 | 玩家停止搬运后，加工口仍自动收到物料并产出下一件。换一个入口，玩家能独立接通。 |
| 熟悉的短线能运转，新用途使单线供给吃紧 | 先扩一处产能。有两个去向争用一路供料时再引出分流，并逐步教授满足当前产线所需的发电、燃料和接线。 | 玩家能指出哪台设备在等什么，改造一处后，看见实际交付恢复或增加。 |
| 曙港的第一束光需要工厂提供新物料 | 按眼前用途依次引入硅矿、镜片、镜阵组装与发射。入轨后才安排地面跟踪和校准芯补给。每项工艺都有可观察的供需任务。 | 玩家将所需物料送到使用地点，完成发射，随后能预见或观察到试照期间的用电高峰。 |
| 平时能运行的工厂到了试照窗口供电吃紧 | 此时开放储能和窗口准备情况，也接受增加基荷或错峰等有效方案。首次成功后引入日照补能。 | 玩家通过第一城的照明窗口，看见光带扫过工厂，接收设备在日照时发电。 |
| 玩家已经亲手建成一段可交付的产线，现在还需要再建同样的一段 | 引入套件生产、布局记录与蓝图部署。让玩家用熟悉的产线生产扩建材料，再亲自为新厂段接通供给。 | 新厂段制造的套件实际到仓。曙港四厂段切片展示各段近期交付和累计交付条件。 |
| 本地工厂已有产能，远处的第二城仍收不到货 | 引入跨区班线，再按装卸和末端短缺安排任务。第三城开放后，用相邻窗口引入多站排班。 | 玩家能把货送到第二城，再让第二、第三城连续通过相邻窗口。 |
| 单站已能点亮，需要让三城周期运行 | 开放三城连续验收与每站下一轮准备线。 | 连续完成三个完整周期并恢复备战储备，进入自由扩建。 |

首次通关以 6–8 小时为平衡目标，第一城试照以开局后 45–75 分钟为目标。章节进度由可用产线、运输能力或实际运行窗口验证。物料数量用于制造和运行，关键解锁以行为验收为主。关卡时长、需求量、窗口配置和配方系数由试玩校准。

### 可验证的产能跃迁

建造站把既有产能投入新产线，新增产线再为后续扩建生产设备。供料与供电充足时，可多段并联复制。达到源头产量、物流容量或电网限制时，实际交付量受瓶颈约束。界面应区分装机产量、实测交付和当前限制因素。

平衡示例是每段产出 4 套设备/分钟，部署一段需 16 套。物资充足且可并行安装时，新一批同等规模的厂段每一代约需 4 分钟备料，装机产能可从 4 增到 8、16、32 套/分钟。施工与接线时间另计。若共享主干只支撑四段，第五段上线后仍需先改造供给，才能增加实际交付。

## 技术架构

| 层 | 技术与职责 |
|---|---|
| 模拟 | Rust 编译为 WebAssembly，由专用 Web Worker 驱动。模拟端持有权威状态，以 30 Hz 的固定步长推进，通过批量命令接收建造、配方或调度操作。 |
| 渲染 | TypeScript 驱动 WebGL 2。通过实例化批绘共用的几何与材质，按视野裁剪并按缩放级别调整显示细节。画面在模拟快照间插值，镜头响应独立于固定步长。 |
| 界面 | TypeScript、HTML、CSS。键鼠和触控复用同一组游戏命令。界面从模拟状态读取已开放的操作，模拟端最终验证解锁条件、建造成本、地形冲突和资源消耗。 |
| 数据传输 | Worker 将可视状态打包到可转移的 `ArrayBuffer`，回收并复用缓冲。镜头区域变化时请求对应数据，区域外的工厂继续模拟。基线采用单 Worker，适合普通静态托管。 |
| 资源 | 全程零位图资源。地图、建筑、货物、照明和特效使用程序生成的几何、图元和着色器。 |
| 存档 | IndexedDB 版本化本地存档，支持导入和导出。先验证候选档的版本与数据，再替换当前会话。V14 保存地图版本。存档记录按格计容的物品数量、电缆施工支付、设备、蓝图、配方、工序、物流、地面物品、储能与游戏进度。V4 至 V13 保留原地图，V4 至 V9 沿用旧版工艺，V4 至 V8 的时间字段换算到 30 Hz。 |
| 构建与部署 | Vite 产出静态文件，GitHub Actions 部署到 GitHub Pages。生产构建需验证仓库子路径下的 JS、Worker 与 `.wasm` 加载及存档往返。 |

### 模拟热点

- 连续皮带按运输段处理。通过紧凑队列表达间距、到达时间和回压，把物流处理集中在运输段端点、分合流、装卸和库存变化上。验证直行、环路、满载、反压释放和施工时的物料守恒。
- 接线变更时重建受影响的电网连通关系，正常运行时按供电区结算。休眠设备由电力、库存或下游容量变化唤醒。
- 班线维护批次、线路时刻和站场容量，沿固定线路派发货箱。移动端和桌面保持同一模拟规则，渲染质量可独立调节。

### 性能验收候选值

以 50,000 格输送带、20,000 件在途货物和 3,000 台活跃设备建立可复现压力场景，覆盖持续运转、堵塞回传和电网拆接。桌面候选指标为模拟步 p95 ≤ 8 ms，1080p 下约 10,000 个可视实例时帧时间 p95 ≤ 17 ms。记录测试硬件、浏览器、内存和批量建造尖峰。移动端帧预算与密集场景规模由真机原型测定。

## 内容数据与本地化

维护者在部署前通过项目配置选择数据集，也可修改数据文件内容或为某一类数据指定文件，再构建 GitHub Pages 静态产物。构建时校验数据引用、数值和默认语言资源，从同一份数据生成模拟数值表及前端目录。Rust 在模拟步中使用紧凑的数值索引。文本、图标与语言资源由前端读取。切换数据集时根据版本与 ID 映射检查存档兼容性。

首期外置现有物品和机器的参数，保留已有注册 ID 与存档映射。数据引用稳定的内容 ID，文件顺序可独立调整。数据注册扩展后，可添加普通物品，也可使用已实现的采矿、加工或运输行为定义新型号。Rust 实现合流轮转、交叉通道、班线等行为，机器数据指定行为和参数。

| 数据 | 配置范围 |
|---|---|
| 物品 | 稳定 ID、名称与描述的翻译键、程序化图标 ID、单格堆叠上限 |
| 配方 | 稳定 ID、名称与描述的翻译键、加工类别、输入、输出、副产物及数量、设备基础周期、兼容机器、设备解锁条件、可选的手工周期与手工解锁条件 |
| 矿脉与开采 | 矿种、产物、每周期产量、基础开采周期、允许的矿机等级、手采周期 |
| 机器与物流 | 建造成本、占地尺寸、物资端口位置、储物格数、进出料缓存格数、额定耗电、发电与储能、输送节拍与在途位置 |
| 模块 | 适用机器、总安装容量、同类模块上限、速度与耗电修正。模块物品的背包堆叠上限由物品表定义 |
| 发展阶段 | 前置阶段、交付地点、需求物品与数量、奖励。奖励可开放建筑、配方与区域，也可提高背包格数、指定物品的堆叠上限、倍速与地图最大视野 |
| 任务 | 前置任务、目标类型、目标参数、标题、描述、提示与奖励。目标参数可引用物品、站点、时长和次数 |
| 手册 | 操作条目的稳定 ID、标题与正文翻译键、对应的教学事件 |
| 地图与游戏进程 | 开放边界、矿脉及站点位置、班线班距、站场与货箱格数、照明窗口与储备要求。这些场景参数排在基础目录之后迁移 |

### 堆叠、周期与任务计数

- **容器容量上限**只由容器格数定义，单位是「格」。这条规则适用于背包、储物仓、站场、货箱及设备的物品缓存。判定能否继续存入时，使用现有同类堆叠的余量和可用空格。总件数仅用于显示库存、计算配方和记录交付等用途。
- **单格堆叠上限**由物品定义，单位是「件/格」。每格只容纳一种物品。`stackLimit` 省略时取 **100**，不可堆叠的物品取 **1**。同一种物品可以占用多个格。阶段奖励可提高背包格数，也可覆盖指定物品的单格堆叠上限。[库存容量迁移](inventory-handoff.md#容器计容迁移)
- 制作以配方基础周期为起点，机器加工倍率和已安装模块共同决定实际周期。机器采矿以矿脉或采矿配方的基础周期为起点，由矿机等级调整。模拟将设备的有效周期向上取整为固定步数，最少为一个模拟步。界面读取实际周期作为进度条分母。手采用独立的按住时长。
- 任务按目标类型读对应状态。「持有」读库存，「生产」读累计生产量，「交付」读指定站点实际收货记录。任务也可引用持续供电或连续通过照明窗口的结果。阶段交付由模拟一次结算材料和奖励，关联任务读取同一份交付进度。

### 本地化接口

物品、机器、配方、任务、阶段及手册数据以 `nameKey`、`titleKey`、`descriptionKey` 等稳定键引用独立语言文件。TypeScript 界面统一通过 `t(key, params)` 解析文本。带数量和时间的句子使用插值与复数规则，数值和单位按当前语言格式化。

前端选用 **i18next 核心库**，由静态构建打包语言资源，默认及回退语言为 `zh-CN`。模拟与存档保留原始 ID、状态码及数值，语言偏好单独保存。切换语言刷新目录、描述和任务提示。首期迁移现有中文，并以第二份样例语言资源验证切换和回退。[i18next 资源载入](https://www.i18next.com/how-to/add-or-load-translations) · [回退规则](https://www.i18next.com/principles/fallback)

[静态数据与本地化交接](data-driven-handoff.md)记录实现顺序与验收用例。

### 地图语言

永夜地表使用深蓝灰网格。铁矿、铜矿、硅矿、煤矿和货物用颜色与形状区分，设备用轮廓和方向标记区分。输送带箭头表示流向，高速带用双箭头。近景显示在途物资，货物沿模拟确定的轨迹移动，堵塞时停在格上。已铺电缆常态显示为青色虚线和菱形接点，日常操作及其他施工时半透明。铺缆和拆缆时提高对比度。选中的格子用青色框，施工草稿用金色框，冲突格和拆除预览用红色。设备检查器用文字区分缺料、缺电和堵塞。轨道视图预示金色光带的位置，照明时光带移动，已点亮的城市窗口变为暖色。

已铺输送带只在上游出口对接下游入口的格边画出连接，单纯贴邻的带面保留间隙。施工预览标出当前可用端口。普通带合流时，侧线弯入干线，合流点之后共用一条带面和一组出货箭头。合流器用独立外壳呈现等样式的入口和唯一出口。交叉器用跨桥轮廓画出两条各自贯通的路径。[端口连接外观](conveyor-handoff.md#端口连接外观)

地图几何、建筑、货物和光照全部用代码生成。实例化绘制复用顶点数据，近景显示单件货物，远景保留线路、流向与告警。移动端可独立下调渲染分辨率和装饰密度，固定步长和全局模拟规则一致。

### 屏幕与输入

- 开场以铁矿点为中心。顶栏显示物资和「档案」，地图提供回到工厂与缩放操作。「任务」「操作」「建造」和「手册」从新局开启，轨道从发射阶段开放。
- 桌面与手机竖屏在地图两侧顶部竖排导航。左侧是「任务」「手册」，右侧是「操作」「建造」。入口使用图标和名称，按钮间留有空隙。桌面抽屉收起时入口靠屏幕边缘，展开时入口随抽屉移到朝向地图的一边，与面板顶部对齐。竖屏的入口固定在两侧顶部，抽屉从底部打开，一次显示一个。
- 手机横屏将四个入口横排在底栏，内容从各自一侧打开。桌面和横屏允许两侧抽屉并排打开，横屏中央保留地图操作区。横屏新局先显示地图，开场任务通过底栏打开。底栏同时提供已解锁的「轨道」和模拟速度。
- 点页面入口打开对应页，再点当前高亮的按钮收起本侧抽屉。点同侧另一个入口直接切页。开合保留镜头、设备选中和施工草稿，地图位置保持稳定。界面支持系统安全区，页面入口的触控区域至少为 44 × 44 CSS 像素。
- 屏幕方向变化时保留镜头焦点、选中对象和施工草稿。建造、排障、调度、存档和读档均可通过可见按钮在两种方向完成。
- 单指拖动地图平移，双指捏合围绕焦点缩放，同时提供缩放按钮。鼠标中键按住拖动时始终平移，建造模式的左键拖铺仍可用。地图手势由 Pointer Events 处理，面板保留正常滚动行为。手势取消及第二指加入时不会提交编辑。

### 建造与排障

建造抽屉分为「建筑」和「蓝图」两个标签。建筑目录按开采、加工、物流、电力和轨道分组，组名两侧用细线分隔。标题右侧的红底羊角锤按钮用于拆设备，左边的红色断缆图标用于拆电缆。电缆以插头和线缆图标归入电力组。鼠标悬停、键盘聚焦或点按建筑图标可查用途、功率及用料，缺少的材料标红。机器、电缆和各等级输送带均可直接点目录图标选中。选中建造或拆除工具时抽屉继续展开，图标保持选中边框。再次点同一图标、施工条「取消」或鼠标右键均可取消。

未选用施工工具时，点空地或未建设备的矿脉会留在当前建造标签。点已建成的设备会打开操作详情。

「蓝图」标签在首次照明后提供标准厂段和本局蓝图库。框选地图并命名后新增一份蓝图，列表显示尺寸、设备数和套件需求。玩家可分别预览、部署、重命名或删除已保存的蓝图。保存或取消框选后回到蓝图页。蓝图库随游戏存档导入和导出。[蓝图库接口与验收](inventory-handoff.md#蓝图库)

开采目录展示已开放的简易、工业和强化工业矿机。各级矿机可安放在已开放的矿脉上，施工预览显示落点产物和采矿速率。工业与强化工业矿机还显示耗电。简易采矿机采用独立动力，玩家从机器手动取矿。[矿机等级接口与验收](inventory-handoff.md#矿机等级)

点选位置时出现虚影，点其他格可换址，再点虚影确认建造。此前已有选中格时，先在该格显示虚影。按住虚影约 350 毫秒再拖动可改变朝向，松手只保留预览。也可点旋转图标，桌面还可按住左键用滚轮旋转。施工条显示用料及可用性，确认后由模拟结算。

拆除设备使用同样的定位和确认方式。点设备预览整台设备的占地，点另一台设备换目标，再点预览范围确认。可以从目录或设备详情进入拆除预览，建筑目录保持展开。

机器可占用多个地图格。虚影覆盖整台机器并随旋转改变。机身边上的青色内向箭头表示进料，金色外向箭头表示出料。设备详情显示占地和各端口坐标，可显示数据指定的端口名称。铺带需对准实际端口所在格与方向。[占地及端口配置](data-driven-handoff.md#机器尺寸与物资端口)

输送带第一次点虚影锁定起点，继续点地图用 A* 追加路径。点已预览的较早格会回退到该格，再点终点才提交整段。短按拖动沿轨迹铺设，长按虚影拖动用于转向。路径直行穿过现有或本段已预览的输送带时使用交叉器，未解锁时寻路绕行。点有收货端口的设备可设为终点，路线接到设备且保留设备本身。[输送带规划与结算](conveyor-handoff.md#地图铺设)

铺电缆和拆电缆共用输送带的起点锁定、点选寻路、短按拖出轨迹、回退和终点确认。电缆无朝向，可铺在设备占地和输送带所在格。自动拆缆路线仅沿相连的已铺电缆，拖过断点时须调整路线再确认。模拟一次结算整段拆缆，拆掉施工批次的最后一个付费格时退还该批实付材料。[电缆施工与拆除交接](inventory-handoff.md#电缆施工与拆除)

地图设备的悬停或点按简报显示名称、状态、内部物资及数量和用电信息。简报与详情都用细条显示当前采矿或生产周期。进度读取模拟的实际工序，缺电或出料堵塞时跟随模拟停留。生产设备区分当前需求、实际耗电和额定功率。发电设备显示当步输出，详情同时展示所属电网的总发电、请求负荷、可放电功率、储能和缺电设备。未接线的发电设备显示未接入电网。蓄电池显示储能、当步充放电与额定上限。没有施工工具时，任一模式点设备都能打开详情和操作。切换至「操作」保留上次所选格的详情。轨道的「查看电网」定位地面站同网发电设备。发射任务开放轨道操作，窗口信息随跟踪任务出现。选择缺电告警会定位设备。轨道面板显示已开放窗口的起止、站点需求、当前准备度和上次故障。可重试已解锁的窗口。

手采按钮底部细条由左向右填充，当前按住 450 毫秒结算一次。持续按住开始下一轮，松手、移动地图或取消触控会清除未完成的进度。键盘聚焦按钮后，可持续按住空格或回车。

### 物资与机器槽位

物品目录从开局起完整注册。玩家通过可到达的矿区、可用的设备与配方取得物品。阶段推进改变这些获取条件，容器对已注册物品的收纳规则始终一致。

- 背包、储物仓和站场等通用容器按实际占用逐格显示。每格一个图标和本格数量，同种物品超过单格上限时分成多个格子。例如单格上限为 100 件时，117 份铁矿显示为 100 和 17 两格。空容器保留容量显示，可手动存入的容器保留投放入口。投放先补同类未满堆，再占用可用空格。
- 加工机器按所选配方显示进料与出料槽，燃料和交付等固定用途槽按设备定义显示。多格库存逐格显示，固定用途槽在数量为零时仍可查看。

顶栏、设备、站场和照明准备情况使用物资图标与数量。悬停或点按库存格可查名称、本格数量、单格上限和允许的操作。从背包拖出物品时，可投放到允许手动存入的容器区域或匹配的固定进料槽。允许手取的进料、出料和在途货物可拖回背包区域。也可先点选来源，再点容器的存入入口或目标槽位。存入入口和槽位支持键盘激活。

拖动时物资图标与手持数量跟随指针。拖动中或选中来源后可滚轮调量。长按约 0.4 秒开始调量，随后向左减少、向右增加。调好后可上下移动并继续拖放，也可松手保留设定，下次拖放沿用该数量。放到无效目标时物资留在原处。机器的配方、供电及其他详细状态在工厂抽屉里显示。[视觉与模拟接口交接](inventory-handoff.md)

打开设备面板后，双击或双点背包的一格会尝试把该格物资全部存入通用容器或匹配的固定槽位。双击或双点设备里可手取的一格会尝试把该格物资全部取回背包。实际转移量受目标可用容量限制，余量留在原处。拖放、点选调量和背包丢弃都以选中格的数量为上限。

从进料槽可取回未投入工序的物资。从输送带可点「取走」释放对应通道。基础与高速带支持路径批量覆建，施工前检查材料、既有端口和在途货物。交付成功后，物资从带末端沿实际进料口滑入容器或设备，并在入口内侧收隐。[输送带动效](conveyor-handoff.md#带上取货与动效)

### 发展阶段

阶段交付奖励用于提高背包格数、指定物品的单格堆叠上限、时间倍速及可用的缩小范围，开放更高等级的输送带与采矿机。新地图在铁矿教学结束时一次开放全图。开局即可放大检查格子、设备接口和物流连接。两类设备均从建造目录直接放置。首档发展在工厂扩张后开放，玩家建好交付站后从背包一次提交材料。加工机器使用可拆卸的速度模块，其获取方式待设计。[发展阶段与能力上限](progression-handoff.md)

拆机按实付用料返还，背包装不下的物料掉到地上。背包支持指定数量丢弃，地面物品可点按拾取。蓝图返还、旧存档和触控规则见[地面物品交接](ground-items-handoff.md)。部署前的数据选择和配置范围见[静态数据与本地化交接](data-driven-handoff.md)。

### 任务与手册

开场至首次试照的引导任务展示目标、当前指标和具体操作。玩家在常规界面采矿、建造、加工及供电。模拟依据实际结果推进，任务页是否打开不影响结算。「手工制作」是「操作」的常驻入口。新游戏开场手制铁锭、铜锭与铜线，结构件由装配台配方生产。旧版存档沿用手制结构件流程。发展任务可从任务页或交付站设备面板提交。[首档阶段交付](progression-handoff.md#首档阶段交付)

「手册」和「任务」位于左侧抽屉。手册按游戏进度展示已介绍的手势，手采、建造、取送料调量、手工制作、铺带和接线等说明与对应任务共用正文。读取已有进度后可直接回顾。施工中可查手册，切回操作与建造后继续同一份草稿。[开场任务与验收](first-miner.md)

## 实施验收顺序

1. 在桌面和手机上验收新游戏开场。第一次接触游戏的人应能完成手采、制作、安放，并看懂第一份自动产物。
2. 打通手工加工、设备加工与第一次自动送料。观察玩家能否在另一处入口独立接好短带，再引入扩产、供电与故障定位。压力场景单独验证。
3. 从已有产线推进到第一城日出和四厂段扩建。观察玩家能否主动再投资、辨识新增瓶颈，并用实际改造恢复增长。同步验证触屏建造与排障。
4. 串起跨区班线、第三城排班和三轮终局。验证不同工厂布局、同版本存档恢复、手机浏览器及 GitHub Pages 生产构建。
