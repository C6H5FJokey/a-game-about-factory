# 拆机返还与地面物品交接

## 拆机结算

- 安放单台设备时，模拟记录当次实付材料。拆除时将建造材料、设备缓存、已占用的在制原料和该格带上货物合并结算。先使用[已有背包容量规则](game-spec.md#堆叠周期与任务计数)入包，余量落到设备锚点。拆机保留机身下的电缆。
- 输送带按原建造流程支付目标装置用料。原位覆建返还旧装置的实付用料，并保留在途货物的身份、来源和顺序。同型旋转保留原支付记录。
- 用预制件安放的简易采矿机拆除时归还预制件。通过材料安放的设备按原支付记录返还。V4 至 V10 存档导入时，旧设备的建造用料按无记录处理，设备内物料仍可回收，旧简易矿机归还预制件。
- 同一次蓝图部署的设备和新增电缆共用一笔套件支付记录。拆除或替换最后一个组成部分时一次退回套件。布局复用的既有线缆沿用原支付状态。
- 同一次手铺线路为新增的电缆登记一笔实付材料。拆除该批次最后一个付费电缆格时一次退回，溢出物资落在结算格。整段拆缆通过同一次退款校验。

## 拾取和丢弃

- 点按地图上的金边物品标记拾取。近景显示物品图标和数量，标记偏离设备中心以便打开设备详情。同格有多种物料时打开操作面板选取。缩小时相邻堆聚合，点按跨格标记放大到对应位置。
- 点背包物品后选「丢弃物品」，填写数量，再点地图确认落点。处于选落点、铺带、接线等操作时，地面标记暂停响应。丢弃模式可通过提示条或 Esc 取消。
- 同格同物料合并到一个稳定 ID 的地面堆。拾取按模拟结算时的容量入包，部分拾取会显示地面剩余量。整堆取完后再次掉落会获得新 ID，旧拾取请求失效。机器和皮带继续使用各自的物流端口，地面物品由玩家拾取。

## 存档与验收

V11 保存地面堆、后续堆身份和建造支付记录。V12 扩展同一份支付记录，支持按材料结算手铺电缆批次。地面投影只发布存在的物品堆，视野外标记及低倍缩放时的细节由前端裁剪与聚合。

- Rust 和 Wasm 回归覆盖拆机时背包部分可用、满包落地、部分拾取、重复请求、同格合并、边界落点、覆建和蓝图整组返还。V11 往返与 V10 导入已验收。
- 静态数据回归以同一兼容数据集调价后恢复旧支付记录，按实际支出返还。
- Edge 桌面及 390 像素竖屏触控视口验收了指定数量、点地图丢弃、点标记拾取和同格多种物品的选择。
