# 《把白昼送回去》设计规格

游戏从手采铁矿开始，玩家用亲手收集的材料造出第一台采矿机，再逐步接触加工、运输和供电。

- 游戏目标、各阶段的解锁条件、工厂系统与整体验收要求见[完整游戏规格](game-spec.md)。
- [软件架构](software-architecture.md)记录数据流、模块分工、兼容边界、技术债和同类项目的公开实现对照。
- [工程质量基线](quality-baseline.md)记录可复现的性能测量与可维护性指标。[工程 TODO](quality-baseline.md#工程-todo)记录优先级和验收条件。
- [终局负载估算](satisfactory-phase5-load.md)从《幸福工厂》第五阶段的并行产线推导机器规模、吞吐与同时在途量。
- 从第一次采矿到第一次自动入仓，常规操作路径、任务手势与手册回顾见[开场任务与第一条产线](first-miner.md)。
- [视觉评审](game-spec.md#可交互视觉稿)提供开场、手工制作、装配台双击存取、首照排障和三城验收前的真实界面，可切换桌面、手机竖屏和横屏。
- [视觉与模拟接口交接](inventory-handoff.md)记录物资槽位、独立储物仓、批量拆缆结算、手工制作和设备配方选择。设备配方列表布局仍有待办。
- [产物与配方换版交接](recipe-handoff.md)记录材料表、设备配方、建造用料与基准产线验收。
- [输送带与物流装置交接](conveyor-handoff.md)定义合流、交叉、覆建保货、带上取货、多等级和运输动效的数据接口。
- [发展阶段与能力上限](progression-handoff.md)记录背包、倍速、地图、高阶设备和速度模块，以及交付、任务提交和手册的待办。
- [拆机返还与地面物品交接](ground-items-handoff.md)记录实际用料返还、地面堆、拾取、丢弃和兼容验收。
- [内容数据与本地化规格](game-spec.md#内容数据与本地化)定义外置范围、单物品堆叠、周期分层与翻译接口。[静态数据与本地化交接](data-driven-handoff.md)记录构建、迁移和性能验收顺序。
