# 开场任务与第一条产线

新局镜头对准曙港的露天铁矿。桌面与竖屏的「任务」「手册」入口在左侧，「操作」「建造」入口在右侧，手机横屏在底栏切换四个页面。开场任务给出当前目标和对应手势。进度由模拟根据实际采集、建造、转移、生产和交付更新。关闭任务页后，玩家可以沿用同一套界面完成任意达到条件的任务。完成引导后，这些操作仍可重复。已介绍的手势从「手册」回顾，条目与任务共用标题和正文。

## 任务顺序

| 任务 | 常规入口及完成依据 |
|---|---|
| 采集第一份铁矿 | 长按地图上的矿点，或点矿点后在「操作」长按采集。第一份铁矿入背包时推进。后续矿点使用同一操作。 |
| 建造简易采矿机 | 凑够铁矿，在「建造 → 建筑 → 开采」选简易采矿机。点矿点出虚影，再点虚影安放。确认时由模拟结算材料。 |
| 等待自动采矿并取出铁矿 | 点采矿机，在「操作」查看设备进度与出料槽。等铁矿进入出料槽后，把它移到顶栏背包区域。实际取料由模拟确认。 |
| 制作首批铁锭与铜线 | 在「操作 → 手工制作」展开所选物品并按住制作。红色材料表示不足。完成首批铜线后开放发电设备。 |
| 接通首个电网 | 安放燃料发电机和冶炼炉，送入手采的煤，并用铜线铺电缆。选铁锭配方，送料并取走铁锭，用于建造装配台。 |
| 选配方并加工 | 给装配台接电，在设备详情选结构件配方，再手动送入两份铁锭。首批结构件产出后开放一级带。 |
| 让装配台自动收到铁锭 | 用短带连接冶炼炉出料口与装配台。任务在装配台用带上送来的铁锭生产结构件后推进。 |

## 手势与反馈

- 手采每次按住 450 毫秒产出一份。继续按住可反复采集，松手、拖图或捏合会清除未完成的进度。地图长按在矿点显示细条，操作按钮长按在按钮上显示细条。聚焦按钮后可按住空格或回车。
- 建造任务说明换址、再次点虚影确认、长按拖动转向、右键或再次点图标取消。取消和无效放置保留材料。已拆的简易采矿机可以从目录再次安放。
- 第一次取料和送料均说明点选、拖放、滚轮调量和触屏长按横滑。铺带任务说明起点锁定、选点寻路、点旧草稿回退、短按拖铺、长按改方向和点终点确认。接带时按机身上的出料箭头与进料箭头选实际端口。
- 开场数值读取游戏目录。新游戏的简易矿机耗费 10 份铁矿，可安放在任何已开放的矿脉上。每 3 个模拟秒产出一份该格矿物，存入出料缓存，由玩家手动取走。出料缓存按格配置，放不下产物时暂停。[出料缓存迁移](inventory-handoff.md#容器计容迁移)

## 地图边界与矿物分布

矿脉固定在地图上。开局只开放 **13 × 13 格**的铁矿区，让第一次采集和建造集中在眼前。从简易采矿机取出第一份矿后，一次开放 **56 × 34 格**的全地图，镜头保留当前视野。镜头、采集、施工和蓝图共用同一开放边界。

离初始铁矿越远，矿物越丰富。西侧较近处有铜，向东可以找到煤，再往外有硅矿。玩家可以自由选择探索和采集的顺序。制铜线、工业采矿和首照推进设备与任务进度。若进入硅矿教学时背包里已有硅矿，本阶段直接通过。

V14 保存地图版本。V4 至 V13 存档沿用原矿点和边界，新游戏使用开场铁矿区和一次全图开放。

## 任务页与手册

任务页只显示目标、模拟确认的当前进度和带界面名称的操作步骤。供电信息从发电设备详情查看，铺缆从建造目录进入，试照从轨道页完成。手册回顾同一份操作步骤，按存档中的游戏进度提供已介绍的条目。施工途中打开左侧抽屉查手册时，保留原设备、操作页面和施工草稿。

## 衔接加工与自动送料

模拟分别记录收到的带上铁锭和当前批次使用情况。带上货物已经抵达、装配台正在加工时保存并恢复，完成该批后可继续推进。用料见[开场建造用料](recipe-handoff.md#机器建造用料)，物流使用[实际端口](conveyor-handoff.md#物流参数迁移)。

V4 至 V9 导入的存档沿用手制结构件、固定配方压制台和原自动入仓判定。原任务和手册随存档保留。

Edge 生产包验收通过桌面鼠标和 390 像素竖屏触控的长按制作、手册和设备选方。

## 验收

| 场景 | 通过条件 |
|---|---|
| 新局跟随任务 | 目标和手势同时可见，任务内无开工、采集、制作或转移控件。 |
| 新局关闭任务 | 从矿点、建造目录、设备槽位和手工制作完成采矿、首个电网、加工和自动送料。完成开场后，可继续手采和手工制作。 |
| 进度与回顾 | 打开说明不推进模拟。完成行为后任务自动更新，手册保留已出现的说明。读档与后期试玩都能回顾相应条目。 |
| 施工中回顾 | 点「手册」查看手势，再点「建造」回到原有虚影或路线草稿继续施工。 |
| 中途恢复 | 槽位内容、已选配方、在制批次和带上货物随档恢复。已有待安放的旧档矿机仍可使用。 |
| 触控 | 竖屏能同时看见开场矿点和任务入口。可长按矿点、操作按钮，使用横滑调量与碰触确认。 |
