# 开场任务与第一条产线

## 实施计划

1. 逐项核对从手采到首次试照的目标、模拟判定和常规操作入口。用设备的实际进出料、供电和进度描述步骤。
2. 将当前任务的目标、进度和手势写入任务页。手册复用对应手势条目，玩家施工途中也能查阅。
3. 把正式加工和自动送料所需的模拟接口列为交接 TODO。开场沿用当前可操作的产线，模拟进度仍来自实际结算。
4. 走一遍新局，从常规界面采集、建造、取料、制作、送料和铺带。核对手册回顾、触控入口以及离开任务页时的推进。

新局镜头对准曙港的露天铁矿。工厂抽屉从开场提供「任务」「操作」「建造」和「手册」。开场任务给出当前目标和对应手势。进度由模拟根据实际采集、建造、转移、生产和交付更新。关闭任务页后，玩家可以沿用同一套界面完成任意达到条件的任务。完成引导后，这些操作仍可重复。已介绍的手势从「手册」回顾，条目与任务共用标题和正文。

## 任务顺序

| 任务 | 常规入口及完成依据 |
|---|---|
| 采集第一份铁矿 | 长按地图上的矿点，或点矿点后在「操作」长按采集。第一份铁矿入背包时推进。后续矿点使用同一操作。 |
| 建造简易采矿机 | 凑够铁矿，在「建造 → 建筑 → 开采」选简易采矿机。点矿点出虚影，再点虚影安放。确认时由模拟结算材料。 |
| 等待自动采矿并取出铁矿 | 点采矿机，在「操作」查看设备进度与出料槽。等铁矿进入出料槽后，把它移到顶栏同种槽。实际取料由模拟确认。 |
| 手工制作第一份结构件 | 在「操作」面板上方打开「手工制作」，点「结构件 ×1」展开。备齐一份铁矿，按住「长按制作」直到细条填满。缺铁矿时配方和铁矿需求标红，按钮仍显示为禁用。此入口在后续可继续使用。 |
| 选配方并加工 | 在冶炼炉设备详情选择铁矿配方，送料并满足供电要求，以实际产出的结构件为依据。接通电网后再引入装配台，用已开放的单输入非矿物配方演示选配方、送料及电网供电。 |
| 让加工设备自动收到物料 | 用输送带连接有自动出料能力的来源和已选好配方的加工设备。以目标设备实际收料并继续加工为依据。 |

## 手势与反馈

- 手采每次按住 450 毫秒产出一份。继续按住可反复采集，松手、拖图或捏合会清除未完成的进度。地图长按在矿点显示细条，操作按钮长按在按钮上显示细条。聚焦按钮后可按住空格或回车。
- 建造任务说明换址、再次点虚影确认、长按拖动转向、右键或再次点图标取消。取消和无效放置保留材料。已拆的简易采矿机可以从目录再次安放。
- 第一次取料和送料均说明点选、拖放、滚轮调量和触屏长按横滑。铺带任务说明起点锁定、选点寻路、点旧草稿回退、短按拖铺、长按改方向和点终点确认。接带时按机身上的出料箭头与进料箭头选实际端口。
- 开场数值读取游戏目录。当前默认简易矿机耗费 5 份铁矿，每 3 个模拟秒产出一份，最多缓存 8 份。满载时暂停，取出后恢复。

## 任务页与手册

任务页只显示目标、模拟确认的当前进度和带界面名称的操作步骤。供电、燃料、制镜与试照的操作继续在设备、建造、电网和轨道页完成。手册回顾同一份操作步骤，按存档中的战役进度提供已介绍的条目。玩家施工途中打开手册时保留原页面和施工草稿，点「返回」继续操作。

## 衔接加工与自动送料

当前模拟已开放固定配方的压制台和压制台出料至建造仓的可运行路线。任务用可操作的进料槽、真实产物与入仓记录解释当前进度，选配方、装配台电网加工及面向加工设备的自动送料按正式流程交接。

## 验收

| 场景 | 通过条件 |
|---|---|
| 新局跟随任务 | 目标和手势同时可见，任务内无开工、采集、制作或转移控件。 |
| 新局关闭任务 | 从矿点、建造目录、设备槽位和手工制作完成采矿、首台机器、加工和当前自动入仓。完成开场后，可继续手采和手工制作。 |
| 进度与回顾 | 打开说明不推进模拟。完成行为后任务自动更新，手册保留已出现的说明。读档与后期试玩都能回顾相应条目。 |
| 施工中回顾 | 打开手册查看长按旋转或输送带手势，点返回后可继续同一份虚影或路线草稿。 |
| 中途恢复 | 材料不足、已有待安放的旧档矿机、压制台未进料或进行加工时读档，可从常规入口继续操作。 |
| 触控 | 竖屏能同时看见开场矿点和任务入口。可长按矿点、操作按钮，使用横滑调量与碰触确认。 |
