# 开场规格 · 第一台采矿机

本章从新战役第一次显示地图开始，到玩家取走自己造的机器采出的第一批铁矿为止。开场结束时，玩家应能从机器的动作和实际产物判断，刚才手采的工作已经可以交给它。后续加工、运输和供电的引入时机见[战役进程](game-spec.md#战役进程)。

## 第一眼看到什么

镜头对准曙港的一处露天铁矿。矿石的轮廓和亮度使它从暗色地表中显出来，矿点旁只有一个就地动作「长按采集」。按住按钮或矿点都可手采，按钮底部的细条从左向右填充。若保留故事引子，一句「曙港已经很久没有见过日出了」即可，放在场景中，玩家无需关闭弹窗。

新局随身铁矿为零，场上设备为零。玩家第一次采集之前，矿点保持静止。可操作内容只有矿点、镜头和基础系统菜单。拖动到远处、缩小地图、打开菜单或按后期快捷键，看到的仍是本阶段的内容。建造目录、空材料栏、带锁图标、任务树、远处设备标签和故障提示一律从开场界面省去。

## 从第一次采集到机器自己出矿

| 玩家所处的时刻 | 可以做什么 | 画面如何回应，何时推进 |
|---|---|---|
| 面前有一处铁矿 | 按住「长按采集」直到细条填满。 | 矿点有采下碎块的动作，同一处出现短暂的「铁矿 +1」，顶栏首次出现铁矿图标及数量 1。这一份铁矿实际入手后，才出现首个制作目标。 |
| 手里已有第一份铁矿 | 继续在原处采。目标只显示「简易采矿机」「放在铁矿上，会自己采矿」和已有量／所需量。 | 每次有效采集增加一份，进度紧随库存变化。材料够用时原位置出现可用的「制作」，镜头和当前目标保持稳定。 |
| 材料已够 | 主动点「制作」。 | 扣除这一台所需的铁矿，得到一台待安放的机器。界面转为「安放采矿机」，原矿点仍在眼前。制作成功后，继续点按不会再次扣料。 |
| 手里有机器 | 点矿点预览位置，再点「安放」。也可以取消预览，稍后继续。 | 有效预览清楚显示机器与矿层的重合位置。点普通地面时，就地提示「放在铁矿上」，可继续选址。取消预览会保留已经做好的机器。安放成功才开始第一个采矿周期。 |
| 机器已安放 | 可以松手观察。 | 机头在刚才手采的位置工作。第一个周期结束时，矿石从矿层进入机旁的出料格，格中数量从 0 变为 1。此刻完成“第一次自动采矿”。玩家即使一直看着，机器也会继续采，直到出料格已满。 |
| 出料槽里已有矿 | 将采矿机旁出料槽里的铁矿拖至顶栏铁矿槽。 | 选中的来源槽高亮。出料槽减少的数量和顶栏铁矿增加的数量一致。取料后出现手制第一份结构件的目标。 |

制作和安放之间不要求玩家再采一次矿或打开通用建筑目录。简易采矿机可在当前允许建造的任意空闲铁矿点工作。它靠自身动力采集，最初的产物留在机旁，玩家能一趟取走多份。满载时矿石留在格内，取走后恢复采集。后续开放运输时，这台机器可以向皮带出矿，早期投入仍有用途。

## 数值与操作约定

手采一次获得 **1 份铁矿**。供首次试玩的起始参数为 **5 份铁矿制作一台、每 3 个模拟秒自动产出 1 份、机旁可积存 8 份**。界面上的进度、消耗和等待时间读取同一份关卡参数。制作成本、采矿周期和积存上限均可调，最终数值由新人试玩决定。首份铁矿来自玩家自己的采集，初始矿点足以负担整台机器及后续采矿。

手采一轮须持续按住 450 毫秒。保持按住可开始下一轮，松手会清空未完成的进度。拖动地图、捏合、取消手势和取消放置都保留已有物资。键盘聚焦采集按钮后可按住空格或回车。制作会把材料转换为一台设备，安放会把持有的设备放到地图上，这两个动作各自只结算一次。暂停期间自动采矿进度停在原处。恢复同版本存档时，一并恢复已开放的操作、随身铁矿、待安放的设备、已放置机器的周期进度和出料格内容。花完铁矿后仍保留已经学会的制作操作。

## 何时给提示

优先用矿石的变化、机头的动作、物料落点和数量变化说明结果。文字留给动作名称、眼前的材料缺口，以及一次操作为什么没有成功。第一份自动产物落下时，保留矿点和出料格在同一画面，让玩家有时间观察。下一项任务等玩家取料后再出现。

## 验收

| 场景 | 通过条件 |
|---|---|
| 新局先观察再探索 | 挂机不会积累第一份矿。拖动镜头、缩放、按快捷键后仍只能接触开场内容。桌面和手机上均能直接看见矿点和长按按钮。 |
| 采矿并制作 | 短按或中途松手结算零份。连续长按时每填满一次给一份，首份揭示制作目标。差一份时仍可继续采，够用时可制作。快速重复点制作，库存变化与得到的设备数量一致。 |
| 点错位置、取消、重新安放 | 普通地面给出就地反馈。取消后仍能找回待安放的机器，随后放在铁矿上，无须再付材料。 |
| 松手观察，再收取 | 停止手采后至少连续产出两份矿。机旁库存增加，随身库存保持原数。悬停或点按机器可见采矿细条。将两份矿拖至顶栏铁矿槽后，机器继续工作。 |
| 中途离开再回来 | 分别在尚差一份材料、机器待安放、机器正在采矿和机旁有货时保存并恢复。本阶段的下一步都可直接继续，物资与产出进度相符。 |

新人试玩从空白新局开始，观察者先让玩家自己动手。记录他第一眼尝试点哪里、何时发现制作目标、哪一次手采开始只是在凑数，以及机器落下第一份矿时他是否仍以为必须继续点击。之后让玩家在没有步骤提示时取走下一批矿，在后续扩产任务中自行安放第二台设备。若玩家能按完所有按钮却没发现机器替自己做了什么，开场仍需调整。优先调整视线、物料反馈和操作顺序，再决定是否需要补一句文字。
