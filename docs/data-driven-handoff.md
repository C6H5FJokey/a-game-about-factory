# 静态数据与本地化交接

数据范围、堆叠规则、周期分层和本地化接口见[内容数据与本地化规格](game-spec.md#内容数据与本地化)。P0 已从静态数据生成 Rust 与 TypeScript 目录，并沿用现有物品、设备和旧档的数值 ID。

## 1. 构建配置与目录

默认配置在 `data/content.config.json`，其中 `dataset` 选择 `datasets` 中的一项。数据集的 `version` 是存档兼容版本，`files` 指定物品、机器、配方及语言资源。顶层 `files` 可以按类别覆盖文件，也可以在 `files.locales` 单独覆盖一种语言。相对路径以配置文件所在目录为准。可设置 `DAYBREAK_CONTENT_CONFIG` 指向另一份配置，GitHub Pages 手动构建使用 `content_config` 输入。

- `data/registry.json` 记录现有稳定 ID、数值索引和设备行为。构建校验重复 ID、引用、字段、数值、图标 ID 和配方兼容性。文件中的物品与机器排序可以独立调整。
- `npm run content` 生成 TypeScript 目录，Cargo 构建生成 Rust 数值表。模拟按数值索引读取，不在模拟步解析 JSON。Worker 启动时校验界面与 Wasm 的内容指纹。
- V8 起记录数据集、版本和影响在制用料的兼容标识。配方周期、堆叠上限和文案可作为同一兼容版的平衡调整。跨数据集、跨兼容版本或改变现有工序输入用量的带标识存档导入会提示不兼容。V4 至 V7 旧档沿用原 ID 和蓝图，进行中工序的输入用量须与旧档匹配。
- 已有数据文件的 `baseTicks`、`beltInterval` 和 `batteryCapacity` 沿用 20 Hz 时的单位。30 Hz 运行目录将配方周期向上取整到模拟步，将电池容量换成当前每步的能量单位，输送按原每秒速率排定整数步交接。V9 将 V4 至 V8 存档里的时钟、加工进度、物流节拍和储能转换到新单位，数据集兼容标识沿用原值。
- 新游戏使用配方的 `modern` 标记、`handcraft` 规则和设备的 `nextMaterials`、`nextPower`、`nextSpan`、`beltRate`。`handcraft.ticks` 为 30 Hz 模拟步，`beltRate` 为件/分钟/通道。V10 记录可选配方的 ID 和物料兼容信息。导入 V4 至 V9 后用原建造材料与固定配方继续本局。

## 2. 本地化接入

- 物品、机器名称与描述、已迁移的库存提示、操作反馈和第一项任务示例使用 i18next 与静态语言包。默认与回退语言是 `zh-CN`。档案中的语言设置会保存到浏览器。英语是用来验收插值、复数和缺译回退的样例包。
- 每种物品使用自己的 `stackLimit`，省略时是 100，不可堆叠时为 1。第一档可通过 `tierOneStackLimit` 覆盖该物品，省略时沿用其基础值。各容器独立配置格数，界面显示占用、物品描述和单格上限。调低配置后，超格库存可保存和消耗。[容器格数配置](inventory-handoff.md#容器计容迁移)

### 机器尺寸与物资端口

在机器数据条目上增加 `size` 与 `ports`。这个例子可用于现有的 `bench` 条目，其他字段照常保留。

```json
{
  "size": [2, 3],
  "ports": [
    {"role": "input", "x": 0, "y": 1, "side": "west"},
    {"role": "output", "x": 1, "y": 2, "side": "east"}
  ]
}
```

- 尺寸为基础朝向的宽、高，各为 1–8 格，省略时为 `[1, 1]`。坐标从机身左上角的 `(0, 0)` 开始，向东和向南增长。`side` 是端口所处的外边，使用 `east`、`south`、`west` 或 `north`。可选的 `labelKey` 从语言数据读取端口名称。
- 多格机器显式声明端口，`ports: []` 代表没有自动物资端口。单格机器省略 `ports` 时继承现有出入料行为。输送带、电缆和班线站场继续使用单格配置。工业矿机各矿种型号共用 `industrial-miner` 的几何配置，强化工业矿机共用 `reinforced-miner` 的配置。
- 建造锚点是当前朝向下的左上格。旋转时占地和端口一起转动。占地内任一格都能检查、旋转或拆除整机。整机只结算一次建造成本、库存与周期。旋转后占用已有建筑或超出已开放地图时，整次旋转被拒绝。
- 可在机身下接线。供电优先选择锚点所在的电网，锚点无电缆时按地图格序选择第一个占地内已接线的格。整台设备使用一个供电区。
- 蓝图框选须包含整台设备，部署时按整段及设备朝向旋转和校验占地。V8 兼容标识包含显式尺寸与端口几何。端口文案可独立编辑。原默认单格 V8 档仍可恢复。

## 4. 构建与性能验收

- `npm run test:content` 分别构建两套数据的 Wasm，覆盖排序稳定、逐物品堆叠、实际配方周期、描述替换、翻译回退、无效数据拒绝、旧档兼容与数据集隔离。多格验收覆盖旋转冲突、端口接货和出货、机身接线、拆除、地图边界、蓝图旋转和读档。
- `npm run test:bundle` 校验静态包内的 Wasm 签名和存档往返。默认数据集另执行 `npm run test:sim`。
- Edge 验收了两套静态包的仓库子路径、V7 导入、V8 跨数据集拒绝、语言偏好与缺译回退，以及手机视口的逐物品容量简报。
